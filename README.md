# 🎖️ 대한민국 국군 전역일 & D-Day 계산기

군종과 입대일, 기준일을 입력하면 **전역 예정일, 남은 복무일(D-Day), 복무 진행률(%), 그리고 예상 진급 타임라인**을 한눈에 계산해주는 반응형 웹 애플리케이션입니다.

---

## ✨ 주요 기능
1. **다양한 군종 지원**: 육군, 해군, 해병대, 특전사, 카투사(18개월) 및 공군(21개월) 복무 기간 자동 반영
2. **정확한 전역일 및 D-Day 계산**: 윤년 및 월별 말일 차이를 고려한 정확한 전역 예정일 산출
3. **복무 진행률 시각화**: 프로그레스 바(Progress Bar)를 통해 현재 복무 달성률(%) 표시 및 시기별 응원 메시지 제공
4. **예상 진급 타임라인**: 입대일 기준 이병·일병·상병·병장 예상 진급일 자동 계산 및 달성 여부 표시
5. **전역 당일 축하 효과**: 기준일이 전역일(D-Day)과 일치할 경우 화면 내 폭죽(Confetti) 애니메이션 실행
6. **모바일 반응형 UI**: Tailwind CSS를 적용하여 스마트폰과 태블릿, PC 화면 모두에 최적화된 인터페이스 제공

---

## 📖 사용 방법
1. **복무 군종 선택**: 상단 버튼에서 해당하는 군종(육군, 해군, 해병대, 특전사, 카투사, 공군)을 선택합니다.
2. **입대일 입력**: 본인의 입대 날짜를 선택합니다.
3. **기준일 설정**: 기본적으로 오늘 날짜가 자동 입력되며, 특정 날짜 기준으로 계산하고 싶다면 날짜를 변경할 수 있습니다. (`오늘 날짜로 설정` 버튼으로 초기화 가능)
4. **결과 확인**: **`전역일 및 복무 현황 계산하기`** 버튼을 누르면 하단에 상세 결과 리포트가 나타납니다.
